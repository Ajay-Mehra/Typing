## ⚡ Core Engine & Platform Capabilities

<table>
  <tr>
    <td width="50%" valign="top">
      <h4>🎯 Exam-Pattern CBT Simulation</h4>
      <ul>
        <li>A test screen laid out like the TCS iON and court typing software candidates meet in the exam.</li>
        <li>Strict exam-pattern timers with auto-submission and real-time passage scrolling.</li>
        <li>Each exam's own duration (5, 10 or 15 minutes), Backspace rule and passage length, plus custom drills.</li>
      </ul>
    </td>
    <td width="50%" valign="top">
      <h4>⚖️ Exam-Rule Error Calculation</h4>
      <ul>
        <li>SSC-style <strong>full</strong> and <strong>half mistakes</strong>, plus each exam's own method: RRB and CAPF allowances, CPCT net WPM, court mistake caps and KDPH.</li>
        <li>Accurate Gross WPM, Net WPM, keystroke count, and net accuracy calculations.</li>
        <li>Qualification benchmarks mapped directly to official notification cutoffs.</li>
      </ul>
    </td>
  </tr>
  <tr>
    <td width="50%" valign="top">
      <h4>🇮🇳 Bilingual Keyboard Engine</h4>
      <ul>
        <li><strong>English:</strong> Standard QWERTY layout with real-time error highlights.</li>
        <li><strong>Hindi:</strong> Unicode (<strong>Mangal</strong>) output from <strong>Remington GAIL</strong>, <strong>Inscript</strong>, <strong>Kruti Dev / DevLys 010</strong> key layouts and phone keyboards.</li>
      </ul>
    </td>
    <td width="50%" valign="top">
      <h4>📊 Instant Report & Certificates</h4>
      <ul>
        <li>Gross and net WPM, character and word accuracy, and a highlighted mistake review.</li>
        <li>Daily English and Hindi live tests, and exam courses with 200+ English and 100+ Hindi passages.</li>
        <li>QR-verified practice certificates for completed skill milestones.</li>
      </ul>
    </td>
  </tr>
</table>
